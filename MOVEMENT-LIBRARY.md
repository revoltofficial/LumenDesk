# Movement library and laser previews

Open Design → Position → Movement library, or Live → Effects → Movement library. The library includes Circle, Figure eight, Sweep, Vertical sweep, Fan, Wave, Spiral, Zigzag, Cross, Smooth wander, Slow atmosphere and an editable Custom path. Picking a card starts that movement effect on the moving heads; software movement limits blend from the current pose. Disable Movement enabled to stop that effect. Existing other effects and Autopilot can still influence the result.

Each card shows the path and a starting-point marker. Reverse and Phase change travel direction and starting phase. Pan size and Tilt size scale each axis separately; Depth scales both. Together gives every head the same path, Mirrored flips alternate heads horizontally, Alternating offsets alternate heads by half a cycle, and Spread distributes phase across moving heads in patch order. RGB fixtures and lasers do not consume movement phase slots. Cycle timing supports 0.25–64 beats; the effect editor also supports seconds. Fast targets may lag because software speed/acceleration limits remain active.

Star built-in cards or saved movements, then use Favourites only to narrow the library. Save movement stores timing, depth, sizes, direction, phase, coordination and any custom control points in the current show. Recall replaces the edited movement effect without changing its identity. Save the show to retain the library and favourites. Up to 64 custom presets are supported. Other effects stay independent.

Laser scans now have animated schematic previews in the stage and laser controls. Known slots: Double 127, Vertical 135, Vertical double 145, Diagonal 94, Spinning 100, Single 116. Colours use the confirmed Rainbow/White/Purple/Light blue/Green/Blue/Red slots. Off, Master zero, Blackout and Stop hide the laser. Unknown pattern slots have no geometry.

Static mode holds the diagram still; Dynamic animates it. Sound and Automatic previews cycle illustrative scans because those programs are controlled inside the hardware, not returned to the app. Sound preview pulses to LumenDesk's beat clock, not the laser's own microphone. X/Y, size and speed have illustrative preview responses; colour segment is not modeled. These are not calibrated optical patterns or a laser safety simulation. Preview rendering never changes DMX and never starts physical output. Lasers remain excluded from music Autopilot.
